# Siege-Scritps for Logitech-GHub
This script is just a basic recoil script for some guns in R6, it does require customization for your independent setting but will work for any logitech mouse.

I made this simply becuase I'm butt and thought this would be fun, I don't use these in game only in customs with my friends.

Here is a tutorial and demo video 

## How to use
1. Open logitech ghub, on the top right there is the profile menu. Click it then select manage profiles
2. Click the desktop profile
3. Create a new profile, call it whatever you like
4. On that profile click the three dots and scroll down to create lua script
5. Paste the script there, when playing siege have the script open with the console at the bottom
6. When playing make sure caps lock is on then aim and shoot.
7. Too switch guns set the argument for the gun selection if statement to that of your choice

## Tuning
1. Open your script and load into a siege shooting range
2. Adjust values for your sensitivity setting and gun setups
  1. Make sure script is on the correct gun, create a new profile at the top for any new guns
  2. Shoot the gun with the script on, look at where your recoil moves and adjust accordingly.
  3. Horizontal, a positive value moves more right, for vertical a positive value moves more down.
